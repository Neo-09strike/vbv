## 🚀 Key Features Implemented

### 1. 🎁 Automatic Launch Pop-Up (Latest Offers)
- **Automatic Trigger on Load**: Opens smoothly after 650ms to greet every new visitor.

- **One-Click Actions**:
  - **Copy Code**: Instant clipboard copy with animated visual confirmation.
  - **Apply 35% & Shop Now**: Automatically stores the promo code into active cart session and smoothly scrolls down to the catalog.
  - **Re-Openable Anytime**: Can be opened from the top pulsing announcement bar or the **Offers** navigation tab.

### 3. 🔍 Live Search & Dynamic Filter Engine
- **Instant Search Bar**: Filter by clothing type, keywords, or GSM specs in real-time.
- **Quick Category Pills**: One-click filtering (All, Tees, Hoodies, Cargoes, Jackets, Accessories).
- **Sort Dropdown**: Sort by Featured Drops, Price (Low to High), Price (High to Low), Biggest Discount (% Off), and Top Quality Rating.

### 4. 🛒 Interactive Cart Drawer & Checkout Engine
- **Slide-In Drawer**: Non-intrusive flyout cart accessible from the header or mobile bottom bar.
- **Dynamic Quantity Controls**: Increment, decrement, or remove items with real-time Indian Rupee subtotal computation.
- **Free Delivery Radar**: Real-time progress bar showing exactly how many rupees remain until unlocking **FREE Express Delivery (over ₹999)**.
- **Promo Code Engine**: Test codes include:
  - `VYRATEEN35`: Flat 35% discount on the entire cart.
  - `FREEDELIVERY`: 100% free priority courier delivery across India.
  - `VYRA500`: ₹500 instant deduction for combo orders over ₹1,999.
- **Seamless Checkout Flow**: Placing an order clears the cart, generates a real-time Tracking ID (e.g., `#VV-94812`), and redirects straight into the Live Tracker!

## 🛠️ Tech Stack & Senior Engineering Standards

- **Zero-Dependency Architecture**: Runs in any modern browser without needing `npm install` or complex build pipelines.
- **Semantic HTML5 & Modern CSS3**: CSS custom properties (variables), Flexbox/Grid, Glassmorphism, animations, responsive breakpoints (`@media`).
- **ES6+ Vanilla JavaScript**: Reactive state management pattern (`AppState`), decoupled event listeners, and `localStorage` persistence.
- **Lucide Icons**: Crisp, lightweight vector iconography.

## 💻 How to Run

1. Open `index.html` directly in your favorite browser (Chrome, Edge, Safari, Firefox).
2. Or serve it via Python or any static server:
   ```bash
   python -m http.server 3000
   ```
   and visit `http://localhost:3000`.
